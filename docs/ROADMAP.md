# 演进路线

## 当前成熟度

当前版本为 **0.1 可用基础版**：核心本地编辑闭环、层级投影与渐进搜索、跨视口交叉定位、直接依赖审查、鼠标 / 键盘接口创建、自动 / 可直接调整的手动正交路由、模块 resize、移动 / 尺寸吸附、完整包围 / Alt 几何相交框选与多选、当前 Level 全选 / 清空、原子对齐 / 分布、子图复制 / 粘贴 / Duplicate、选中线路聚焦、五类直接手势的视口边缘持续自动平移、低缩放信息收敛、DRC、草稿保护、model-owned `2.0 -> 2.1` 逐步迁移与兼容矩阵、canonical JSON 文件流、公开编辑合同单测，以及 200 / 400 大型设计全量几何门禁、1000 / 2000 压力 Canvas 视口裁剪和可重复 observation-only 性能报告已经成立；崩溃恢复、历史容量策略、固定 CI 性能预算和完整跨浏览器仍未达到生产级。

路线图记录真实完成的迭代，不用计划数量冒充执行数量。长期目标可以拆成 100 个小步，但每一行都必须对应实际代码、验证或文档证据。

## 优先级

- **P0 — 数据安全与可恢复性**：保存正确性、Undo / Redo、Schema 兼容、崩溃恢复、无效加载与原子编辑。
- **P1 — 核心设计与审查体验**：高频流程、选择、层级、Inspector、DRC、接口追踪、空状态与弹窗行为。
- **P2 — 规模、导航与操作效率**：大工程性能、布局与路由可读性、上下文保持、搜索和专业键盘效率。
- **P3 — 视觉、可访问性与平台完成度**：视觉一致性、细节打磨、响应式、读屏与跨浏览器 / 桌面平台。
- **P4 — 新高级能力与生态**：设计 Diff、源码 / AI 适配器、仓库集成、协作与发布能力。

P0 未收敛前不扩展协作或服务端事实源。源码分析作为适配器消费公开 Schema，不进入 model、editor 或 routing 内部。

## 阶段路线

### Phase 0：事实源与质量基线

- 收敛 README、产品、架构、质量与路线图的文档职责。
- 审计模型、编辑、IO、布局、路由、Studio、样式与测试。
- 用新用户、专业日常用户、代码审查者三种视角真实 Dogfooding。
- 建立持续迭代记录，替代一次性验证报告。

### Phase 1：编辑可靠性

- 清理首屏 runtime warning，建立导航前 console gate。
- 保护 Inspector 草稿，统一弹窗焦点与关闭语义。
- 完成空状态、命令模型和错误反馈一致性。
- 拆出 model / editor / serialization 单元测试。

### Phase 2：文件与 Schema 生命周期

- 定义 v2.x 兼容规则、迁移注册表和 golden fixtures。
- 增加恢复副本、异常关闭恢复与保存失败反馈。
- 建立确定性序列化合同与设计文件兼容矩阵。

### Phase 3：专业审查工作流

- 设计快照 Diff、受影响模块和接口合同变化。
- DRC 筛选、分组、修复说明与源码定位。
- 审查状态和可导出报告保持为派生 / 协作事实，不污染设计合同。

### Phase 4：规模、平台与生态

- 建立大型和压力设计，完成性能测量与降级策略。
- 扩展 Firefox、WebKit、Windows 与 macOS 验证。
- 提供语言无关的源码 / AI 适配器接口和示例。
- 在文件与版本模型成熟后评估仓库集成和多人协作。

## 迭代规则

每轮只解决一个最高收益的独立问题，并完成：实际观察 → 根因 → Owner / 不变量 → 最小完整实现 → 清理旧路径 → 类型 / 测试 / 浏览器 / 截图验证。

- 每 10 轮做一次产品与质量回顾，重排优先级并删除失效计划。
- 每 25 轮做一次架构收敛检查，审计 Owner、依赖方向、事实源和公共 API。
- 任何数据丢失、错误保存、Schema 破坏或崩溃问题立即提升为 P0。
- 不为了凑轮次拆分同一根因，也不把文档描述算成多轮实现。

## Iteration 63–72：draw.io 源码对照第一批

对照基线固定为 draw.io 官方仓库提交 [`a1f615b`](https://github.com/jgraph/drawio/tree/a1f615b7f5a5237da71de2ce2f057b5fa70b0aeb)。参考的是交互职责划分和几何提交方式，不复制图标、模板、通用样式系统或文件格式；本项目仍以 `BlockDesignDocument` 为唯一设计事实，以 `DesignOperation` 为唯一持久编辑入口。

长期目标不是完成十轮后停止，而是在代码模块设计允许的对象和规则内达到 draw.io 同等级的图形操作水平：每个合法动作都必须有直接操作、可见预览、明确合法性、一次原子提交、Undo / Redo、键盘等价路径、持久重载和大图降级证据。通用图形库、自由旋转、图片 / 表格与装饰样式不属于本产品对象语言，不能用这些功能数量替代模块与接口操作的深度。

源码给出的关键结构证据：connection arrows 与 connection points 是彼此独立的 View action，而不是同一个图形符号（[`Actions.js`](https://github.com/jgraph/drawio/blob/a1f615b7f5a5237da71de2ce2f057b5fa70b0aeb/src/main/webapp/js/grapheditor/Actions.js#L1212-L1283)）；resize 由 vertex handler 负责预览、尺寸 / 边缘吸附和最终 geometry，并另有同一 geometry 的键盘入口（[`Graph.js`](https://github.com/jgraph/drawio/blob/a1f615b7f5a5237da71de2ce2f057b5fa70b0aeb/src/main/webapp/js/grapheditor/Graph.js#L27419-L28129)、[`EditorUi.js`](https://github.com/jgraph/drawio/blob/a1f615b7f5a5237da71de2ce2f057b5fa70b0aeb/src/main/webapp/js/grapheditor/EditorUi.js#L7520-L7753)）；edge handler 独立拥有端点与虚拟折点，手动折点会退出自动路由，Clear Waypoints 再回到自动状态（[`Graph.js`](https://github.com/jgraph/drawio/blob/a1f615b7f5a5237da71de2ce2f057b5fa70b0aeb/src/main/webapp/js/grapheditor/Graph.js#L26387-L26445)、[`Actions.js`](https://github.com/jgraph/drawio/blob/a1f615b7f5a5237da71de2ce2f057b5fa70b0aeb/src/main/webapp/js/grapheditor/Actions.js#L1628-L1725)）；对齐与分布是可搜索的具名 action，不散落在面板事件里，默认分布按中心点等距并包在一次批量 update 中（[`Actions.js`](https://github.com/jgraph/drawio/blob/a1f615b7f5a5237da71de2ce2f057b5fa70b0aeb/src/main/webapp/js/grapheditor/Actions.js#L582-L639)、[`Graph.js`](https://github.com/jgraph/drawio/blob/a1f615b7f5a5237da71de2ce2f057b5fa70b0aeb/src/main/webapp/js/grapheditor/Graph.js#L21223-L21348)）。

Iteration 70 曾把复制链排为下一优先级；用户随后提供的真实密集端口与层级截图证明自动路线仍会因哈希 lane、模块对 channel 和事后偏移产生回钩、近距共路与不可解释跳线。该证据直接否定“旧路由已经收敛”的前提，因此 Iteration 71 先建立独立场景级数学策略。draw.io 新 `LibavoidRouting` 同样将 editor binding 与路由核心分开，明确 fixed anchor / jetty、手工 waypoint 接管，以及 multi-edge nudging 与 independent deterministic solve 的取舍（[`LibavoidRouting.js`](https://github.com/jgraph/drawio/blob/a1f615b7f5a5237da71de2ce2f057b5fa70b0aeb/src/main/webapp/js/diagramly/LibavoidRouting.js#L1275-L1380)、[`LibavoidRouting.js`](https://github.com/jgraph/drawio/blob/a1f615b7f5a5237da71de2ce2f057b5fa70b0aeb/src/main/webapp/js/diagramly/LibavoidRouting.js#L3110-L3122)）；本项目吸收职责边界，不复制其文件格式或非确定性策略。
